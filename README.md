# Boonhug website mockup

Responsive Next.js App Router mockup based on the supplied Boonhug sitemap and visual references.

## Run locally

```bash
npm install
npm run dev
```

The app uses Tailwind CSS, shadcn-style components built on Radix UI, and local mock data. No database, payment, or external service is connected.

## Pages

- `/` Home
- `/adoption` Adoption listing with dog/cat filters
- `/donation` Donation categories and organization cards
- `/donation/voice` Donation detail with amount presets and QR modal
- `/profile` Donor profile mockup
- `/shop` Boonhug shop product page
- `/about` About Boonhug
